Conductors#

A conductor is a material where charges are mobile but constrained to the confines of the conductor. In an external electric field those charges rearrange themselves into their lowest energy configuration. This configuration (in the limit of enough electrons) has a remarkable property: the electric field inside the conductor is zero. The excess charge ends up on the surface, and the interior is perfectly screened. This is why you are safe inside a metal car during a lightning strike (a “Faraday cage”).

In this module we will start only with point charges and Coulomb’s law and see this behavior directly. We will:

  1. Write a function that computes the electric field of a set of point charges, and test it on one and two charges.

  2. Place charges on a sphere by hand and check that the field inside vanishes.

  3. Let the charges move on their own — pushing each other around by the Coulomb force (gently damped so they don’t oscillate but converge to some configuration) and watch them discover the surface arrangement themselves: in a solid ball, on a sphere sitting in an external field, in a hemisphere, and in a cube.

In this project we will work in natural units: the Coulomb constant is \(K_E = 1\) and our conductor has radius \(R = 1\). The mobile charges are electrons, each carrying charge \(q = -1\) (in units of the elementary charge), since electrons are what actually move in a metal. Run the setup cell below before you start — it defines a few helper functions so you can focus on the physics.

def GetSpherePoints(numPoints):
    "Return ~numPoints points spread (nearly) evenly over the unit sphere."
    pts, n, r = [], numPoints, 1.0
    alpha = 4.0*np.pi*r*r/n
    d = np.sqrt(alpha)
    m_nu = int(np.round(np.pi/d))
    d_nu = np.pi/m_nu
    d_phi = alpha/d_nu
    for m in range(m_nu):
        nu = np.pi*(m+0.5)/m_nu
        m_phi = int(np.round(2*np.pi*np.sin(nu)/d_phi))
        for k in range(m_phi):
            phi = 2*np.pi*k/m_phi
            pts.append((r*np.sin(nu)*np.cos(phi),
                        r*np.sin(nu)*np.sin(phi),
                        r*np.cos(nu)))
    return np.array(pts)

def GetLinePoints(the_start,the_end,num_points,dir="x"):
    """num_points evenly spaced points on a line through the origin along the x, y, or z axis.
    Returns (field_locs, xs): field_locs is (num_points, 3), ready to pass to `field`;
    xs is the 1D array of coordinates along the line (handy for the horizontal axis of a plot)."""
    xs  = np.linspace(the_start, the_end, num_points)
    if dir=="x":
        field_locs = np.stack([xs, np.zeros_like(xs), np.zeros_like(xs)], axis=1)
        return field_locs,xs
    elif dir=="y":
        field_locs = np.stack([np.zeros_like(xs), xs,np.zeros_like(xs)], axis=1)
        return field_locs,xs
    elif dir=="z":
        field_locs = np.stack([np.zeros_like(xs),np.zeros_like(xs),xs], axis=1)
        return field_locs,xs
    raise ValueError("dir must be 'x', 'y', or 'z'")

def GetSquarePoints(the_start,the_end,num_points=45,dir='xy'):
    """A num_points x num_points grid covering [the_start, the_end]^2 in the z = 0 plane (dir='xy')
    or the y = 0 plane (dir='xz').  Returns (field_locs, X, Y): field_locs is the flattened
    (num_points**2, 3) array of grid points, ready to pass to `field`; X, Y are the 2D grid
    coordinates (as from np.meshgrid).  For dir='xz', Y holds the z coordinate."""
    g = np.linspace(the_start,the_end, num_points)
    X, Y = np.meshgrid(g, g)
    if dir=='xy':
        field_locs_XY = np.stack([X.ravel(), Y.ravel(), np.zeros(X.size)], axis=1)
        return field_locs_XY,X,Y
    elif dir=='xz':
        field_locs_XY = np.stack([X.ravel(), np.zeros(X.size),Y.ravel()], axis=1)
        return field_locs_XY,X,Y
    raise ValueError("dir must be 'xy' or 'xz'")


def GetBallPoints(N, R):
    """N random points uniform in the volume of a ball of radius R (r = R u^(1/3) so they are not
    bunched at the center).  Returns an (N, 3) array."""
    u = np.random.uniform(0, 1, N)
    costheta = np.random.uniform(-1, 1, N)
    phi = np.random.uniform(0, 2*np.pi, N)
    r = R*np.cbrt(u); theta = np.arccos(costheta)
    return np.stack([r*np.sin(theta)*np.cos(phi),
                     r*np.sin(theta)*np.sin(phi),
                     r*np.cos(theta)], axis=1)

def GetHemispherePoints(N, R):
    """N random points uniform in the volume of the upper half-ball (z >= 0) of radius R.
    Returns an (N, 3) array."""
    u = np.random.uniform(0, 1, N)
    costheta = np.random.uniform(0, 1, N)        # upper half only
    phi = np.random.uniform(0, 2*np.pi, N)
    r = R*np.cbrt(u); theta = np.arccos(costheta)
    return np.stack([r*np.sin(theta)*np.cos(phi),
                     r*np.sin(theta)*np.sin(phi),
                     r*np.cos(theta)], axis=1)

Exercise 0. The Electric Field of Point Charges#

We will be interested in computing the electric field of a series of point charges. This can be done by adding up the Coulomb fields over a collection of point charges. We will start by writing this function which takes point charges and field locations and computes the field at those locations for those point charges. This will be used later for conductors.

a. Writing field#

The field of a single point charge \(q\) sitting at \(\mathbf r_i\), measured at a point \(\mathbf r\), is

\[ \mathbf E(\mathbf r) = K_E\, q\, \frac{\mathbf r - \mathbf r_i}{\left(|\mathbf r - \mathbf r_i|^2 + \epsilon\right)^{3/2}}, \]

and the field of many charges is just the sum of these (superposition). Write a function

def field(charges, points, q):
    "E field at each of the M points (M,3) due to N charges (N,3), each of charge q; returns (M,3)."
    ...
    return E

  • charges is an (N, 3) array: the positions of the \(N\) charges (row \(i\) is \(\mathbf r_i\)).

  • points is an (M, 3) array: the places where you want to measure the field.

  • q is the charge on each of them. For our electrons that is Q_E = -1.

  • It returns an (M, 3) array: row \(k\) is the field vector \(\mathbf E\) at points[k].

A few pointers:

  • The small softening \(\epsilon = 10^{-4}\) in the equation above is added to \(\lvert\mathbf r - \mathbf r_i\rvert^2\) before raising it to the \(3/2\) power, so a field point that lands right on a charge doesn’t divide by zero. (Exercise 2 relies on this: it evaluates the field at each charge, where the charge’s own term becomes \(0/(10^{-4})^{3/2} = 0\).)

  • Start simple. The easiest fast thing to do is to start with no electric field E = np.zeros_like(points) and write a for loop over the charges, compute \(\mathbf r - \mathbf r_i\), d=points - charges[i] (shape (M, 3)) and add that charge’s field at all \(M\) field locations at once. When you divide the (M, 3) displacements by the (M,) cubed distances, NumPy needs the distances as a column: compute those distances with np.sum(d**2, axis=1, keepdims=True) (shape (M, 1)) so the division applies to all three components.

  • Optional: remove the loop. points[:, None, :] - charges[None, :, :] has shape (M, N, 3); it holds every displacement vector \(\mathbf r - \mathbf r_i\) at once. Form the cubed distances (shape (M, N)), divide (index them as r3[:, :, None] so they broadcast against the last axis), and sum over the charge axis (axis=1).

  • Start with charges = np.asarray(charges, float) (and the same for points) so that you can pass in plain Python lists like [[0, 0, 0]].

Quick check. Put one electron at the origin and measure the field at \((1,0,0)\) and \((2,0,0)\) in a single call. The field should point inward (toward \(-x\), since an electron is negative), have magnitude \(1\) at \(x=1\) (you’ll see \(0.99985\) because of the softening), and fall off like \(1/r^2\), so the two magnitudes are in the ratio \(4:1\). For example:

E = field([[0, 0, 0]], [[1, 0, 0], [2, 0, 0]], Q_E)
print(E)

np.linalg.norm(E[0]) gives the magnitude of the first field vector.

Exercise 2. Letting the Charges Rearrange Themselves#

In the previous exercise, we placed the charges by hand. In a real conductor the electrons find their optimal location themselves. Let’s simulate that. To do that, we will let them charges (\(m=1\)) move under their dynamics but remove the kinetic energy so they don’t keep moving. The relevant equations of motion written as two first-order equations for its position \(\mathbf r_i\) and velocity \(\mathbf v_i\):

\[ \begin{aligned} \dot{\mathbf r}_i &= \mathbf v_i, \cr \dot{\mathbf v}_i &= Q_E\,\mathbf E(\mathbf r_i) \;-\; \gamma\,\mathbf v_i \;+\; \mathbf f_\mathrm{wall}(\mathbf r_i), \end{aligned} \tag{1} \]

where \(\mathbf E(\mathbf r)\) is the electric field of all the electrons,

\[ \mathbf E(\mathbf r) = K_E\, Q_E \sum_{j} \frac{\mathbf r - \mathbf r_j}{\left(|\mathbf r - \mathbf r_j|^2 + \epsilon\right)^{3/2}}, \]

which is exactly what your field from Exercise 0 computes: field(pos, pos, Q_E) gives \(\mathbf E\) at every charge’s own position.

The first term is the Coulomb force \(\mathbf F = q\mathbf E\) on electron \(i\) (with \(m = 1\), force and acceleration are the same). A charge’s own term in the sum is zero, since \(\mathbf r_i - \mathbf r_i = 0\), so it feels no force from itself. Because \(Q_E \cdot Q_E = +1\), electrons repel. The small softening \(\epsilon = 10^{-4}\) (the one built into field) keeps nearby pairs from blowing up. The second term is a drag force (coefficient \(\gamma\)) that bleeds off kinetic energy so the system relaxes into its lowest-energy configuration instead of oscillating forever. The third, \(\mathbf f_\mathrm{wall}\), is a stiff restoring force (stiffness \(k\)) that keeps the charges inside the conductor. Its form depends on the shape of the conductor, so we give it in each part below. Because the wall is a stiff spring rather than a perfectly hard wall, charges pressed against it come to rest slightly outside it, where the spring balances their mutual repulsion (a few percent of \(R\) for the sphere, a bit more for the cube). That is expected.

Integrating with solve_ivp. solve_ivp integrates a system \(\dot{\mathbf y} = f(t, \mathbf y)\) where \(\mathbf y\) is a single flat array. So we pack the positions and velocities of all \(N\) charges into one state vector,

\[ \texttt{state} = [\,\underbrace{x_0,y_0,z_0,\,x_1,y_1,z_1,\dots}_{3N\ \text{positions}},\ \underbrace{v_{x0},v_{y0},v_{z0},\dots}_{3N\ \text{velocities}}\,], \]

and write a right-hand-side function rhs(t, state) that returns \([\dot{\mathbf r},\ \dot{\mathbf v}]\) from Eq. (1), packed the same way. The call is

t_eval = np.linspace(0, T_MAX, 60)       # the 60 times at which to save the state
sol = solve_ivp(rhs, (0, T_MAX), state0, t_eval=t_eval, method='RK45', atol=1e-3)

where state0 is the initial state. We use atol=1e-3 rather than the default because positions and velocities are of order 1, so this is plenty accurate and much faster. The result holds the saved times in sol.t (length 60) and the saved states in sol.y, an array of shape (6N, 60): column k is the full state at time sol.t[k]. So, for example, the positions at the last saved time are sol.y[:3*N, -1].reshape(N, 3).

The number of charges \(N\), the run time \(T_\mathrm{max}\) (T_MAX), and anything else specific to a geometry are given in each part. The same template works for every geometry below — only the wall force and the initial positions change, plus (in part b) an external charge added to \(\mathbf E\).

a. Charges in a solid metal ball#

Step 1 — Set up and run the dynamics.

Write the right-hand side rhs(t, state) of Eq. (1) for charges inside a ball of radius \(R\). Here is the skeleton: the first two lines unpack the state, and the last line packs the answer back up.

def rhs(t, state):
    pos = state[:3*N].reshape(N, 3)     # (N, 3): row i is r_i
    vel = state[3*N:].reshape(N, 3)     # (N, 3): row i is v_i
    acc = ...                           # (N, 3): row i is dv_i/dt from Eq. (1)
    return np.concatenate([vel.ravel(), acc.ravel()])

Build acc one term of Eq. (1) at a time:

  • Coulomb force. field(pos, pos, Q_E) is the field of all the electrons, evaluated at every electron. Multiply by the charge \(Q_E\) to get the force.

  • Drag. Subtract DRAG*vel.

  • Wall. A one-sided wall that pushes a charge back only when it strays outside (\(r > R\)). Writing \(r_i = \lvert\mathbf r_i\rvert\) and \(\hat{\mathbf r}_i = \mathbf r_i / r_i\),

    \[ \mathbf f_\mathrm{wall}(\mathbf r_i) = \begin{cases} -k\,(r_i - R)\,\hat{\mathbf r}_i & r_i > R \cr 0 & r_i \le R. \end{cases} \]

    This is the first time we need an “if” applied to every charge at once, which np.where does:

    r = np.linalg.norm(pos, axis=1, keepdims=True)          # (N, 1): distance of each charge
acc += np.where(r > R, -K_WALL*(r - R)*(pos/r), 0.0)     # wall force where r > R, else 0

    keepdims=True keeps r as a column, so pos/r divides each row by that charge’s distance (giving \(\hat{\mathbf r}_i\)). np.where(condition, a, b) takes a where the condition is true and b where it is false.

Initial conditions. Start the charges at random positions throughout the volume of the ball, at rest. GetBallPoints(N, R) returns such positions as an (N, 3) array; flatten it with .ravel() to build the initial state:

init_pos = GetBallPoints(N, R)
state0 = np.concatenate([init_pos.ravel(), np.zeros(3*N)])

Then integrate with solve_ivp as described above, and print sol.success to check that the integration finished.

Step 4 — Did the system actually relax?

The drag removes energy, so the total energy should fall as the electrons move into a screening configuration, and then flatten out once they have settled. Check this by computing the kinetic and potential energy at every saved frame. Loop over the frames, pulling out the positions and velocities of frame k from column k of sol.y:

num_frames = len(sol.t)
ke = np.zeros(num_frames)
pe = np.zeros(num_frames)
for k in range(num_frames):
    pos = sol.y[:3*N, k].reshape(N, 3)     # positions at frame k (first 3N entries of the state)
    vel = sol.y[3*N:, k].reshape(N, 3)     # velocities at frame k (last 3N entries)
    # ke[k] = ...
    # pe[k] = ...

  • Kinetic energy. \(K = \sum_i \tfrac12 m \lvert\mathbf v_i\rvert^2\), with \(m = 1\).

  • Potential energy. The Coulomb energy is a sum over pairs, \(U = \sum_{i<j} K_E\, q_i q_j / \lvert\mathbf r_i - \mathbf r_j\rvert\). Rather than looping over pairs, you can get it from the forces you already know how to compute. For Coulomb interactions,

    \[ U = \sum_i \mathbf r_i \cdot \mathbf F_i, \qquad \mathbf F_i = Q_E\,\mathbf E(\mathbf r_i). \]

    In code, compute the forces with field as in your rhs, then np.sum(pos*F) adds up all the dot products \(\mathbf r_i\cdot\mathbf F_i\) at once. (Because field is softened, this agrees with the exact pair sum to about 0.1%.)

Plot two graphs side by side, using fig, axes = GetPlot(1, 2, w=11, h=4) (then axes[0] is the left panel and axes[1] the right):

  • left: the potential energy and the total energy (kinetic + potential) vs. time (sol.t);

  • right: the kinetic energy vs. time on a log \(y\)-scale, since it falls by orders of magnitude.

A few things you will notice. The kinetic energy at \(t = 0\) is exactly zero (the charges start at rest), so the log plot can’t show that first point. Late in the run the kinetic energy levels off around \(0.1\) instead of falling forever; that is numerical jitter from the solver tolerance and doesn’t matter. And our “total” ignores the small energy stored in the springy wall (about 1% of the total), which is why it isn’t exactly the conserved quantity.

Deliverables

  • The two energy-vs-time graphs.

  • The total energy at the start and at the end of the run.

b. A conductor in an external field#

So far the electrons have relaxed without any external charge or field. Now we bring up an external point charge \(Q_\mathrm{ext}\) off to one side and watch the surface electrons rearrange to cancel its field inside the conductor. Pin the electrons to the spherical surface (a two-sided wall holds them at \(r = R\)). As the electrons rearrange, they pile up so as to cancel the external field everywhere inside the sphere — induced screening.

We use a positive external charge so the electrons are attracted to it: they crowd onto the near side (making it negative) and leave the far side electron-poor (relatively positive).

Step 1 — Set up and run. The field each electron feels now has two pieces: the field of the other electrons, as before, plus the field of the fixed external charge \(Q_\mathrm{ext}\) at \(\mathbf r_\mathrm{ext}\),

\[ \mathbf E(\mathbf r) \;\to\; \mathbf E(\mathbf r) + K_E\, Q_\mathrm{ext}\, \frac{\mathbf r - \mathbf r_\mathrm{ext}}{\left(|\mathbf r - \mathbf r_\mathrm{ext}|^2 + \epsilon\right)^{3/2}}. \]

That is just one more call to your field, with a single “charge” at POS_EXT carrying charge Q_EXT: field([POS_EXT], pos, Q_EXT). Add it to the electrons’ field and multiply the total by \(Q_E\) to get the force, exactly as in part (a). The sign takes care of itself: \(Q_E < 0\) and \(Q_\mathrm{ext} > 0\), so the force pulls the electrons toward the external charge.

Instead of part (a)’s one-sided wall, use a two-sided spring that holds the charges on the shell \(r = R\) whether they stray outside or inside:

\[ \mathbf f_\mathrm{wall}(\mathbf r_i) = -k\,(r_i - R)\,\hat{\mathbf r}_i \quad \text{(for all } r_i\text{)}. \]

In code this is part (a)’s wall without the np.where. Write a new rhs with the Coulomb force (electrons plus external charge), drag, and this wall.

Start the charges spread evenly on the sphere, at rest. Because GetSpherePoints returns only approximately the number you ask for, reset N to the number you actually got before building the state:

charges = GetSpherePoints(N)
N = len(charges)
state0 = np.concatenate([charges.ravel(), np.zeros(3*N)])

c. A hemispherical conductor#

The surface arrangement isn’t special to spheres. Take a solid hemisphere (the top half of the ball, \(z \ge 0\)) and let charges relax inside it. Now there are two walls: the curved cap \(r = R\) and the flat base \(z = 0\). The charges should coat the curved surface and the flat disk, again leaving the interior screened.

Write rhs with both constraints: part (a)’s one-sided spherical wall for \(r > R\), plus a floor that pushes up whenever \(z < 0\),

\[ \mathbf f_\mathrm{wall}(\mathbf r_i) = \underbrace{\begin{cases} -k\,(r_i - R)\,\hat{\mathbf r}_i & r_i > R \cr 0 & r_i \le R \end{cases}}_{\text{curved cap}} \;+\; \underbrace{\begin{cases} -k\,z_i\,\hat{\mathbf z} & z_i < 0 \cr 0 & z_i \ge 0 \end{cases}}_{\text{flat floor}}. \]

The curved cap is exactly part (a)’s wall. The floor acts only on the \(z\)-component of the acceleration, the third column of acc:

z = pos[:, 2]
acc[:, 2] += np.where(z < 0, -K_WALL*z, 0.0)

Start the charges at random positions inside the hemisphere, at rest. GetHemispherePoints(N, R) returns them as an (N, 3) array (just like GetBallPoints), so use .ravel() when you build state0. Then run it and check the result:

  • a 3D scatter of the final positions;

  • a field map on the \(x\)–\(z\) slice (the plane \(y = 0\), which cuts through the flat base). As in Exercise 0d, use GetSquarePoints(-2, 2, dir='xz') and pass Ez (not Ey) to PlotSlice as the second in-plane component;

  • an animation with animate_charges.

Parameters. \(N = 150\) charges, \(T_\mathrm{max} = 8\).

d. A cubic conductor#

We will now do a conductor with corners - a cube. Confine the charges to a cube of side \(L\) (walls at \(x, y, z = \pm L/2\)) and let them relax. Conductors with sharp features concentrate charge there — you should find the charges crowding onto the faces and especially piling up at the edges and corners, where the field just outside is largest.

Write rhs with a one-sided wall on each of the six faces. Each face pushes back only along its own axis, so apply this to each component \(x_i\), \(y_i\), \(z_i\) separately (shown for \(x\)):

\[ f_{\mathrm{wall},x}(\mathbf r_i) = \begin{cases} -k\,(x_i - L/2) & x_i > L/2 \cr -k\,(x_i + L/2) & x_i < -L/2 \cr 0 & \text{otherwise.} \end{cases} \]

Because each component is treated the same way, you don’t need to split pos into columns: np.where works element by element on the whole (N, 3) array. For example, the three faces on the positive side are

acc += np.where(pos > SIDE/2, -K_WALL*(pos - SIDE/2), 0.0)

and the negative side is the same idea.

Start the charges at random positions inside the cube, at rest: np.random.uniform(-SIDE/2, SIDE/2, (N, 3)) gives an (N, 3) array of uniform random points. With 800 charges each run takes up to a minute or so. Then:

  1. show the final positions in a 3D scatter;

  2. check that the interior is screened with a field map on the \(z = 0\) slice (GetSquarePoints(-2, 2));

  3. animate the relaxation with animate_charges.

Parameters. \(N = 800\) charges, side \(L = 2\) (SIDE), \(T_\mathrm{max} = 4\).

Deliverables
